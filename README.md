# 🎯 Simulador de Redondo

Simulador interativo de campeonatos em **formato suíço + mata-mata**. Primeiro campeonato: **PGL Major Singapore 2026 (CS2)** — 32 times, 3 fases suíças e playoffs.

## Recursos
- Clique para escolher vencedores (MD3: clique de novo para alternar 2-0 / 2-1)
- Pareamentos suíços automáticos no padrão Valve (Buchholz, sem revanches)
- 🎲 Simular partida, rodada, fase ou campeonato inteiro — modos *Realista*, *Favoritos* e *Caos 50/50*
- Probabilidades por Monte Carlo (até 5.000 campeonatos) a partir das suas escolhas
- Força dos times editável · Desfazer (Ctrl+Z) · Link compartilhável · Salvo no navegador
- Responsivo (PC e celular) e animado

## Rodar
```bash
npm install
npm run dev
```
